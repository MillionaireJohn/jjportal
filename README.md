# JJ Portal — Ningji Lemon Tea 🍋

Staff management system for Ningji Lemon Tea.

## How to deploy updates to Netlify

1. Edit `index.html` (get new file from Claude)
2. Run: `git add . && git commit -m "update" && git push`
3. Netlify auto-deploys in ~30 seconds ✅

## First time setup

1. Install Node.js from https://nodejs.org
2. Run: `npm install`
3. Run: `netlify login`
4. Connect repo to Netlify (done once)
